This repository is the implementation of a rule-driven agent platform prototype, inspired by classic instruction table engines.

Developers:

    - Katelyn Clark / Graduate Intern (2026)

Folder structure:

    cmd/ - Main entry point for running the process engine.

    internal/ - Core runtime components, including shared working memory, instruction definitions, and the parser/interpreter.
    
    programs/ - Process programs (instruction tables) executed by the engine.
